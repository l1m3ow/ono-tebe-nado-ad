# Оно тебе надо

Учебный проект Яндекс Практикума. Статическая страница аукциона с обложкой, карточками лотов, описанием аукциона и контактами.

Для просмотра откройте `index.html` в браузере. Сборка и установка зависимостей не требуются. Макет рассчитан на ширину 1100 пикселей.

[Репозиторий проекта](https://github.com/l1m3ow/ono-tebe-nado-ad)
